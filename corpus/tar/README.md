# TAR corpus

Generated by `generate.sh` with GNU tar 1.35, gzip, bzip2, xz and zstd
(`sh corpus/tar/generate.sh`). Times are fixed to 2025-03-04 05:06:07.123456789 UTC.

| File | Purpose |
|---|---|
| `gnu.tar` | GNU format: `L` long names, `./` root entry, symlink, hard link, empty dir |
| `pax.tar` | pax: UTF-8 names, long paths, nanosecond mtimes |
| `ustar.tar`, `v7.tar` | older dialects |
| `pax.tar.{gz,bz2,xz,zst}`, `pax.tgz` | compressed TAR, one-step tree |
| `a.txt.gz`, `b.txt.{bz2,xz,zst}` | single compressed files |
| `members.txt.gz` | two concatenated gzip members |
| `truncated.tar.gz` | first 600 bytes of `pax.tar.gz` |
| `sparse.tar` | GNU sparse file (reported as unsupported) |
