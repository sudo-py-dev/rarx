# ZIP corpus

Generated by `generate.py` (Info-ZIP 3.0 `zip` + CPython `zipfile` + hand-built records).
Regenerate with `python3 -I corpus/zip/generate.py`.

| File | Producer | Purpose |
|---|---|---|
| `infozip-basic.zip` | Info-ZIP 3.0 | Deflate + Store, folders, empty file, symlink, UT/ux extras |
| `infozip-encrypted.zip` | Info-ZIP 3.0 `-P` | ZipCrypto item → reported as encrypted |
| `python-utf8.zip` | CPython zipfile | UTF-8 flag (bit 11) names |
| `zip64-stored.zip` | hand-built | ZIP64 extra fields, ZIP64 end record + locator |
| `sfx-prefixed.exe` | `infozip-basic.zip` + 4 KiB `MZ` stub | SFX offset shift, extension fallback |
| `corrupt-crc.zip` | CPython zipfile, CRC patched | checksum failure handling |
| `evil-traversal.zip` | CPython zipfile | `..`, absolute, drive-letter names |
| `evil-symlink.zip` | CPython zipfile | absolute, escaping and chained symlinks |
