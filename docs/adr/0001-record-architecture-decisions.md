# 1. Record architecture decisions

- Status: accepted
- Date: 2026-10-23

## Context

AGENT.md requires an ADR for public API changes, dropped features and open questions.

## Decision

Architecture decisions are recorded as numbered Markdown files in `docs/adr/`, using
this template: Status, Date, Context, Decision, Consequences.

## Consequences

Open "verify/?" items in AGENT.md are closed by adding an ADR and updating AGENT.md in
the same change.
